# ParaDebriefing

Cross-platform Expo app for a five-fingers paragliding debriefing after each flight.

## Features

- Open directly into the saved debriefing list for quicker access
- Keep saved flights concise in a horizontal overview with date/time and location
- Capture one debriefing per flight across all five fingers via a dialog
- Add optional external flight links (for example XContest) per debriefing
- Edit existing debriefings directly from the list
- Runs from one React Native codebase for Android and iPhone

## Run locally

```bash
npm install
npm start
```

Then open the Expo project on Android or iOS.
